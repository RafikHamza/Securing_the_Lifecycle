# ESP32-S3 Firmware Sources

The physical ESP32-S3 module runs post-quantum ML-KEM-1024 decapsulation benchmark firmware compiled under ESP-IDF v4.4.7 (`vh-mlkem-esp32s3-bench`).

Firmware build configuration:
- CPU Frequency: 240 MHz
- Flash Size: 16 MB
- Output Format: JSON stream over UART at 115200 baud.
